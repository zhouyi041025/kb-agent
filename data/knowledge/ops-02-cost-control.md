# 大模型应用的成本控制

## 成本从哪来

成本等于输入 token 数乘以输入单价，加上输出 token 数乘以输出单价。输出单价通常是输入的几倍，所以控制输出长度往往比压缩输入更划算。检索增强的输入长度由召回条数决定，召回从十条减到五条，输入成本立刻减半，这也是"召回质量比数量重要"的经济学理由。

## 降本手段

结果缓存是最直接的，相同问题直接复用答案，命中率在高频问答场景可以做到三成以上。语义缓存更进一步，用向量相似度判断两个问题是否等价，能覆盖措辞不同的重复提问，但要承担误判风险，阈值要设得保守。上下文压缩指对召回片段做摘要或截断，只保留与问题相关的句子。模型分流是把简单问题交给小模型，只有需要复杂推理时才调用大模型，用一个轻量分类器或规则路由即可。

## 怎么量化

每次调用记录输入输出 token 数并换算成金额，按接口、按用户、按天聚合。只看总量无法定位成本异常的来源。发现某个接口单次成本异常高时，先看是不是上下文长度失控，再看是不是重试次数过多。
